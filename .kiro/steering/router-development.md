# Router Development Guide

This steering applies when working on router packages under `packages/psmcp-router-*/`.

---

## Router Structure

Each router follows this layout:

```
packages/psmcp-router-<name>/
├── pyproject.toml
├── README.md
└── src/
    └── psmcp_router_<name>/
        ├── __init__.py        → exports router + __version__
        ├── _version.py        → auto-generated by hatch-vcs (gitignored)
        ├── service.py         → FastMCP instance + tool/resource/prompt definitions
        └── *.md               → MCP resources served to LLM clients at runtime
```

---

## pyproject.toml Template

```toml
[project]
name = "psmcp-router-<name>"
description = "PS-MCP router plugin: <name> (<brief description>)."
readme = "README.md"
requires-python = ">=3.13,<3.14"
dynamic = ["version"]
dependencies = [
    "ps-mcp>=0.1.0,<1.0",
    # router-specific deps here
]

[build-system]
requires = ["hatchling>=1.25", "hatch-vcs>=0.4"]
build-backend = "hatchling.build"

[tool.hatch.version]
source = "vcs"
raw-options = { root = "../.." }

[tool.hatch.build.hooks.vcs]
version-file = "src/psmcp_router_<name>/_version.py"

[tool.hatch.build.targets.wheel]
packages = ["src/psmcp_router_<name>"]

[project.entry-points."psmcp.routers"]
<name> = "psmcp_router_<name>:<router_variable>"
```

## Service File Pattern

```python
"""<Router description>."""

import logging

from fastmcp import FastMCP
from psmcp.core.auth import resolve_token

logger = logging.getLogger(__name__)

router = FastMCP(name="<Router Display Name>")


@router.tool
async def my_tool(param: str, token: str | None = None) -> dict:
    """Tool docstring — this is shown to LLM clients.

    Args:
        param: Description.
        token: Optional ArcGIS token. Resolved automatically if not provided.

    Returns:
        Dict with results.
    """
    resolved_token = resolve_token(token)
    # implementation...
```

> Note: Use `str | None` (PEP 604 union syntax) instead of `Optional[str]` — Python 3.13 supports this natively.

## Checklist for Router Changes

- [ ] `resolve_token()` used for all token handling (never read `ARCGIS_TOKEN` directly)
- [ ] `httpx.AsyncClient` for HTTP calls (not `requests`)
- [ ] Logging uses `logging.getLogger(__name__)` with lazy formatting
- [ ] Environment variables documented in the router's `README.md`
- [ ] Entry point declared in `pyproject.toml`
- [ ] Router exported from `__init__.py`
- [ ] `__version__` exposed from `_version.py`
- [ ] `.md` resource files included in the package (if any)
- [ ] Router added to `[tool.uv.sources]` in root `pyproject.toml`
- [ ] Verify discovery after changes: `psmcp router list`

## Common Patterns

### Reading env vars

```python
import os

SOME_URL = os.getenv("MY_ROUTER_URL", "https://default.example.com")
VERIFY_SSL = os.getenv("ARCGIS_VERIFY_SSL", "True").lower() != "false"
```

### Async HTTP with SSL control

```python
import httpx

async with httpx.AsyncClient(timeout=30.0, verify=VERIFY_SSL) as client:
    resp = await client.get(url, params=params, headers={"Authorization": f"Bearer {token}"})
    resp.raise_for_status()
    return resp.json()
```

### Serving .md files as MCP resources

```python
import os

@router.resource(uri="resource://my-router/guide")
def guide_resource() -> str:
    """Provide guidance to LLM clients."""
    current_dir = os.path.dirname(os.path.abspath(__file__))
    md_path = os.path.join(current_dir, "guide.md")
    with open(md_path, "r", encoding="utf-8") as f:
        return f.read()
```

## Auth Plugin Structure (for reference)

Auth plugins follow a similar pattern but use the `psmcp.auth` entry-point group:

```
packages/psmcp-auth-<name>/
├── pyproject.toml
├── README.md
└── src/
    └── psmcp_auth_<name>/
        ├── __init__.py        → exports factory function + __version__
        └── _version.py        → auto-generated by hatch-vcs (gitignored)
```

Entry point:
```toml
[project.entry-points."psmcp.auth"]
<name> = "psmcp_auth_<name>:create_auth_provider"
```

The factory function returns an auth provider instance or `None` (to skip activation).
